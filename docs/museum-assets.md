# Museum assets

The museum uses actual Three.js geometry and materials in a single React Three Fiber scene. The selected concept is a design reference, not a background image in the application.

| File                                                 | Source and use                                                                                                                                                                                                                                          |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `materials/limestone.webp`, `materials/plaster.webp` | Generated for this project from the selected Daylight Museum art direction. Repeated material color and subtle bump maps; compressed to 1024 × 1024 WebP.                                                                                               |
| `models/duck.glb`                                    | [Khronos glTF Sample Models: Duck](https://github.com/KhronosGroup/glTF-Sample-Models/tree/master/2.0/Duck). Locally cached version of the duck asset used by the original repository demo.                                                             |
| `materials/daylight.hdr`                             | [Three.js example environment: venice_sunset_1k.hdr](https://github.com/mrdoob/three.js/blob/dev/examples/textures/equirectangular/venice_sunset_1k.hdr). Used for material reflections and indirect lighting; the gallery background is real geometry. |
| `materials/water-normal.jpg`                         | [Three.js example water normal map](https://github.com/mrdoob/three.js/blob/dev/examples/textures/water/Water_1_M_Normal.jpg). Locally cached version of the original duck demo dependency.                                                             |
| `fonts/caslon.ttf`                                   | [Libre Caslon Display](https://github.com/google/fonts/tree/main/ofl/librecaslondisplay). The accompanying `fonts/OFL.txt` is included. Used for the HTML brand and physical labels in the room.                                                        |
| `photos/beach.jpg`                                   | The [Unsplash photo](https://plus.unsplash.com/premium_photo-1676667573109-273586405c96) already referenced by the original Polaroid demo, cached locally at 1024 pixels wide. Five physical prints show different crops of this image.                 |
| `thumbnails/*.webp`                                  | Compressed copies of the repository's eight original screenshots in `.github/assets/screenshots`. Used only in the HTML catalogue and collection dialog.                                                                                                |

Paths above are relative to `public/museum/`. Original source attributions and applicable asset terms remain with their respective creators. The selected generated concept is retained separately at `docs/daylight-museum-reference.webp`.

All eight exhibit models, the room architecture, plants, labels, light fixtures, bench, gates, cage, hoverboard, cars, conveyor, and constellation are implemented in `src/museum/`. The constellation searches the repository's existing `public/companies.json`; it shows a small representative group in the shared room and brings a searched company into that group when selected. The original full constellation remains linked from the inspector.
